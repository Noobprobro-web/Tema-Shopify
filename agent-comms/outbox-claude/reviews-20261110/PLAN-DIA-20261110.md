### 2.2 D-02-Q cantidad (b)

No tocar `readQuantityRules` salvo para exponer `maxOnGrid`, ni los steppers del cajón más allá de lo que hereden. No cambiar Liquid (`main-product.liquid:451-453` ya emite min/step/max). Pruebas: arnés Playwright sintético nuevo en `agent-comms/outbox-claude/harness-D-02-Q-001/` con casos 2/2/4/5, 1/1/x/∞, 3/3/x/10, max < min, valor tecleado 7, inventario como tope (`:1187-1193`) y variante agotada (`:1198`); base `6e9523b` debe fallar el primero. `node --check assets/theme.js`, Theme Check 4.8.0 (`npm ci` y `npx shopify theme check --output json`), `npm run gates:static` sin `gates:package`.
