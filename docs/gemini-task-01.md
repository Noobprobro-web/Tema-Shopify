# Gemini Task 01: Research and Concept Validation

Usa este encargo despues del prompt de contexto general.

## Objetivo

Validar y mejorar la estrategia inicial del tema Shopify antes de implementar.

## Contexto

Codex propone avanzar con el concepto principal `Atelier Flow`: un tema Shopify minimalista editorial para marcas premium de producto fisico, combinando storytelling visual, compra clara y alta personalizacion para merchants.

Conceptos secundarios:

- `Quiet Commerce`: mas funcional, enfocado en conversion y catalogos medianos.
- `Object Gallery`: mas artistico, tipo galeria para objetos de alto valor percibido.

## Tareas

1. Revisa requisitos oficiales actuales de Shopify Theme Store.
2. Identifica riesgos de acceptance para `Atelier Flow`.
3. Investiga 8-12 ecommerce premium/minimalistas actuales, idealmente Shopify o reconocidos por premios de diseno.
4. Resume patrones utiles sin copiar layouts ni assets.
5. Propone 5 oportunidades concretas para hacer el tema mas original.
6. Propone una matriz de templates/secciones necesarias para MVP.
7. Recomienda que tareas deberia tomar Gemini y cuales deberia dejar a Codex.

## Formato de entrega

- Hallazgos clave.
- Riesgos.
- Oportunidades.
- Matriz MVP.
- Recomendacion final.

## Reglas

- Cita fuentes cuando uses requisitos oficiales.
- Marca claramente supuestos.
- Prioriza performance y accesibilidad.
- No propongas dependencias externas pesadas.
- No hagas implementacion todavia.
