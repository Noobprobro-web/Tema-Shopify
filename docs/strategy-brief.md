# Strategy Brief

## Ambicion

Crear un tema Shopify premium que combine minimalismo, ritmo editorial y herramientas comerciales reales. El tema debe sentirse disenado para marcas con producto fisico fuerte, no como una plantilla generica con cards bonitas.

## Hipotesis Principal

El espacio mas interesante esta entre ecommerce premium, storytelling editorial y operacion merchant-friendly. Muchos temas minimalistas son limpios, pero planos. Muchos temas "innovadores" son vistosos, pero pesados. Nuestro tema debe ocupar el punto medio: tactil, ligero, claro y con suficiente personalidad para que Shopify lo vea como una propuesta original.

## Concepto Recomendado: Atelier Flow

Tema minimalista editorial para marcas premium de producto fisico: moda, joyeria, skincare, home decor, wellness, cafe especial, vinos, accesorios y objetos de diseno.

### Diferenciador Visual

- Composicion editorial asimetrica pero tranquila.
- Grids de producto con ritmo: alternar producto, detalle, editorial note y coleccion.
- Tipografia sobria con contraste entre una serif/display de caracter y una sans funcional.
- Paletas neutras con acentos controlados por preset, evitando monocromia plana.
- Motion tactil y sutil: reveals, cambios de foco, microinteracciones de producto y transiciones de coleccion.

### Diferenciador Funcional

- Secciones de compra con narrativa: producto destacado, ritual de uso, materiales, comparativas, colecciones guiadas.
- Product cards enriquecidas pero limpias: swatches, quick add, disponibilidad y segunda imagen sin saturar.
- Presets por industria, no solo por color.
- Ajustes claros para merchants: densidad, mood visual, tipo de hero, ritmo de grid y profundidad editorial.

### Riesgos

- Demasiado motion podria afectar performance o accesibilidad.
- Si el diseno se vuelve demasiado editorial, puede perder conversion.
- Si usamos demasiados presets visuales, se puede volver dificil de mantener.

### Criterio de Exito

Una demo debe comunicar en menos de 5 segundos que no es un clon de Dawn/Horizon, pero tambien debe ser obvio como un merchant vende productos con ella.

## Concepto Alternativo 1: Quiet Commerce

Tema ultra funcional para tiendas con catalogos medianos, enfocado en claridad, filtros, busqueda y compra rapida. Ideal para wellness, ropa basica, suplementos, papeleria, accesorios y marcas DTC.

Fortaleza: conversion y usabilidad.
Riesgo: puede sentirse menos unico si no se trabaja muy bien la direccion visual.

## Concepto Alternativo 2: Object Gallery

Tema tipo galeria/museo para objetos de alto valor percibido: muebles, ceramica, arte, joyeria, decoracion, fotografia y piezas limitadas.

Fortaleza: originalidad visual.
Riesgo: menos universal para merchants y mas exigente en fotografia.

## Direccion Recomendada

Avanzar con Atelier Flow como base y tomar de Quiet Commerce la eficiencia transaccional. Object Gallery queda como preset mas artistico, no como arquitectura principal.

## No Negociables

- Mobile-first real.
- Navegacion clara.
- Product discovery rapido.
- Performance: bajo JS, CSS contenido, imagenes bien dimensionadas.
- Accesibilidad: foco visible, contraste, labels, reduced motion.
- Personalizacion clara desde el theme editor.
- Sin SCSS/Sass.
- Sin depender de apps externas para funciones core.
- Sin clonar temas existentes.
