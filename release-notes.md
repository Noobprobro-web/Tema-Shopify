# Release notes — proposed version 1.1.0

**Draft only:** Johandry must approve the version number and these notes before release. The theme metadata remains at 1.0.0 until that approval.

## Proposed changes

- Updated preset documentation and support references to use Sartorial, Imprint, and Archive.
- Improved accessible names for selected theme controls and retained keyboard focus after collection filtering.
- Excluded the internal documentation and support page templates from the distributable ZIP. The source templates remain in the repository.

## Data migration notice

Product technical specifications and provenance no longer read values from `custom.*` or `sartorial.*` metafields. Existing metafield values will not appear through these blocks. Enter only approved product data in the corresponding theme editor block settings before enabling the blocks.
